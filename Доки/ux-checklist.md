Этот файл — воспроизводимый сценарий приёмки. Незаполненный пункт означает, что ручная проверка ещё не зафиксирована здесь; наличие функции в коде не считается проверкой в реальном браузере.

- Полный frontend: **73 теста пройдены**, `npm run build` проходит (включает TypeScript). Backend повторно: **37 тестов пройдены**.

Встроенный Chromium, настоящий FastAPI на 8000, dev 5174 и готовая сборка 4175: эталон 56.54307; M7 перенесена мышью в Нуру; M4 в тот же район отклонена с причиной; M12 через карту добавлена один раз для всего города. - [ ] M4 и M7 несовместимы в одном районе, но доступны в разных районах.

- [x] При выборе района виден текущий показатель и подсказка, где мера нужнее.

- [ ] Шестая мера, повторная мера и третья мера направления не добавляются.

- [ ] «Отменить» возвращает добавление, удаление, смену района и очистку плана.

## Границы текущей реализации

Пять районов показаны схематично; данные условные. Черновики и план А локальны для браузера и адреса сайта; синхронизации между устройствами нет. История отмены не переживает перезагрузку. Общий лидерборд хранится на сервере, имена команд не защищены учётными записями. PWA, установка приложения, управление телевизором с пульта и запуск с нуля полностью без сети не реализованы.
