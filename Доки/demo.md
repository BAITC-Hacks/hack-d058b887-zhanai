# Демонстрация за пять минут

Цель — показать выбор пяти решений, объяснимые ограничения и влияние плана на районы. Данные условные, эффекты заданы организаторами. Не называем результат прогнозом реальной Астаны.

## Подготовка

1. Выполнить `npm ci` в `frontend/`.
2. Для самостоятельного показа интерфейса запустить `npm run dev:demo`, открыть `http://127.0.0.1:5173` и убедиться, что видна пометка деморежима. Используется IPv4.
3. Для итоговой защиты с вычислением произвольных планов запустить сервер по инструкции человека 1, затем `npm run dev`. Проверить `/api/catalog`, `/api/simulate` и `/api/explain` заранее.
4. Закрыть предыдущий процесс Vite, если он занимает порт 5173. Проверить масштаб страницы и читаемость на ноутбуке защиты.
5. Пройти [чек-лист](acceptance-checklist.md). Готовность демо и готовность интеграции фиксируются отдельно.

23.09.2026 интерфейс проверен на Windows с Node.js 24.11.0, на экранах около 1265×712 и 390×844. Контрольный результат и действия с планом работают в демо. Сохранены [скриншот для ноутбука](../frontend/screenshots/result-desktop.png) и [мобильный скриншот](../frontend/screenshots/result-mobile.png). Видеозапись и репетиция с хронометражем пока не подготовлены; настоящий backend и второй компьютер не проверялись.

## Вариант A: интерфейс без сервера

Это согласованный текущий этап работы без сервера: он проверяет UI и работу с ожидаемым форматом данных. Он не доказывает работу произвольных расчётов и AI.

| Время | Действие | Что сказать |
| --- | --- | --- |
| 0:00–0:30 | Показать шапку, бюджет и пометку режима | «Мы выбираем пять мероприятий в бюджете 100. Сейчас показываем интерфейс на проверочном ответе; данные синтетические». |
| 0:30–1:15 | Открыть карточки районов и фильтры направлений | «У районов разные исходные показатели. Городская мера влияет на все районы, районной нужно назначить один район». |
| 1:15–2:15 | Выбрать M7, M8 и M10 в Нуре, M12 для города, M5 в Сарыарке; для быстрого показа нажать «Загрузить пример» | «Это контрольный набор организаторов. Расход — 95, остаток — 5, выбрано пять разных мер». |
| 2:15–3:15 | Нажать «Рассчитать план», показать результат и показатели районов | «Для этого набора эталонный Score 56,54 против 52,56: прирост около 3,99. Критических показателей стало 0 вместо 2». |
| 3:15–3:50 | Нажать «Объяснить результат», показать пояснение и его статус | «Это подготовленное пояснение без вызова модели. После подключения сервера AI будет получать проверенные факты». |
| 3:50–4:25 | Удалить одну меру, затем изменить район у оставшейся | «Старый результат больше не относится к текущему плану. Неполному набору нельзя приписывать Score 0. Демо не вычисляет новый Score для произвольного набора». |

При желании восстановить результат заново соберите контрольный набор. Порядок выбора мер несущественен; важны пять ID и указанные районы.

## Вариант B: итоговая защита с подключённым сервером

Использовать только после фактической проверки интеграции. Если AI отсутствует, показывать честный статус «без AI» и не заявлять выполненный вызов модели.

| --- | --- | --- |
| 0:00–0:30 | Человек 2 | Объяснить задачу, бюджет, условные данные и активный режим правил. |
| 0:30–1:15 | Человек 2 | Показать районы, фильтры, цену, лаг и область действия меры; начать собирать контрольный набор. |

| 2:50–3:40 | Человек 1 | Изменить район одной из районных мер, заново рассчитать допустимый набор. Показать фактический новый ответ сервера и актуальное пояснение. |

Процентиль, глобальный оптимум, события, лидерборд и экспорт показываем только после реализации и проверки соответствующих серверных возможностей. Числа перебора из плана не подменяют ответ работающего сервера.

## Контроль перед выступлением

- Режим `dataset`: ровно пять мер, максимум две из направления. Контрольный набор не подходит для `all_directions`, поскольку не содержит транспорта.
- Набор: M7/Нура, M8/Нура, M10/Нура, M12/весь город, M5/Сарыарка.
- Расход `95`, остаток `5`; Score `52.55768 → 56.54307`, прирост `3.98539`; критические показатели `2 → 0`.
- Нура: оценка `49.18 → 52.9625`; средняя оценка города `56.8624 → 58.0776`.
- В интерфейсе значения округлены до двух знаков, в расчётных проверках используются полные значения.
- Сбой сети или AI не должен удалять выбранные решения. Ошибка объяснения не делает ранее полученный валидный расчёт недействительным.
- Ответ организаторов о необходимости всех пяти направлений ещё требуется.

Если сервер недоступен, явно перейти к варианту A. Скриншоты и фиксированный ответ можно использовать как резерв интерфейса; они не заменяют проверенный живой расчёт.
