- [ ] Все показанные числа совпадают с серверным ответом с учётом округления отображения.

Статус: по договорённости текущий этап выполняется без backend. Эти совместные проверки отложены до его передачи человеком 1; это отдельная приёмка интеграции, а не незавершённая часть текущего интерфейсного этапа. Список требуемых материалов — в [README](../README.md#что-передать-от-человека-1).

## Дополнения

Поиск улучшений, оптимум, процентиль, события, лидерборд и экспорт пока не входят в подтверждённую интеграцию. После появления соответствующих API проверяются отдельными сценариями. Предложение улучшения не должно автоматически заменять пользовательский план без его действия.

Автоматический тест с имитированным `/api/improve` подтвердил, что UI применяет предложение только после нажатия «Применить предложение». Это проверка поведения интерфейса, а не качества серверного оптимизатора.

Дополнительно: установка `npm ci --offline --no-audit --no-fund` и сборка прошли в отдельной чистой копии frontend на этом же компьютере. Использован локальный npm-кэш; установка с пустым кэшем и второй ноутбук не проверялись. Диалог правил закрывается клавишей Escape.
