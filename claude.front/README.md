# Интерфейс «Аким на 5 часов»

React 19, TypeScript, Vite, Tailwind 4. Основа дизайна Claude сохранена: светлый экран с каталогом слева, схемой города и портфелем в центре, результатом и анализом справа. Контуры районов интегрированы из [Astana Scheme](<../Astana Scheme/README.md>): упрощённые границы OpenStreetMap, © участники OpenStreetMap, ODbL. Серверная часть находится в соседней папке `backend`; полный запуск описан в [корневом README](../README.md).

## Быстрый запуск

При запущенном FastAPI на `127.0.0.1:8000`:

```text
npm ci
npm run dev
```

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Настоящий API по умолчанию, localhost:5173 |
| `npm run dev:lan` | Доступ через локальный IP компьютера с телефона |
| `npm run dev:demo` | Явный режим браузерного демо |
| `npm test` | Vitest, состояния, API и компоненты |
| `npm run typecheck` | TypeScript |
| `npm run build` | Проверка типов и сборка в dist |
| `npm run preview -- --port 4173` | Локальная проверка готовой сборки |

Демо также включается параметром `?demo=1`. Переменные из `.env.example` необязательны: без них используются HTTP и относительный `/api`. При старом локальном `.env` с `VITE_API_MODE=mock` замените значение на `http` или удалите эту настройку, чтобы перейти на сервер. Режим выбирается явно, ошибка API не включает mock автоматически.

Vite dev и preview проксируют `/api` на IPv4-адрес `http://127.0.0.1:8000`. При размещении `dist` этот маршрут должен обслуживать reverse proxy вашего хостинга. API-ключи хранятся только в корневом серверном `.env`.

## Работа с планом

- **Перетаскивание и список.** На компьютере перетащите карточку M на район карты. Допустимые районы показывают подсказки; несовместимые назначения отклоняются с причиной. Кнопка «Выбрать район» открывает доступную альтернативу с выпадающим списком и текущим значением нужного показателя. Городская мера применяется ко всему городу.
- **Обратная связь.** Видны прогресс 0/5, бюджет, причины недоступности, синергии и квартал начала эффекта. Короткие сообщения подтверждают изменения. Принятые идеи обучающих интерфейсов — ясное следующее действие, небольшой прогресс и возможность исправить выбор.
- **Черновик и фиксация.** После каждого решения сервер пересчитывает карту. До пяти допустимых мер официальный Score отсутствует. «Зафиксировать план» сохраняет результат команды и запускает анализ; дальнейшее изменение возвращает план в черновик.
- **Восстановление.** «Отменить» возвращает до 20 последних изменений текущей сессии. Выбранные меры, событие и один сохранённый «План А» переживают обновление страницы в этом браузере. Значения Score не сохраняются как готовый результат.
- **Сравнение.** Сохраните А, измените план, изучите разницу мер и баллов. Разница баллов показывается только при одинаковых исходных условиях, версии данных и правилах. Предложение оптимизатора применяется отдельной кнопкой.
- **Разные экраны.** Широкий экран использует три колонки, средний — две, узкий — одну. На телефоне каталог открывается отдельной панелью через закреплённую кнопку «Добавить решение». «На экран» скрывает каталог и увеличивает Score для показа.
- **Доступность.** Есть управление кнопками и списками с клавиатуры, видимый фокус, Escape для закрытия панелей, текстовые состояния критичности и поддержка reduced motion. Перетаскивание не обязательно.

Черновики привязаны к режиму HTTP/demo, версии датасета и набору правил. Они не синхронизируются между устройствами; приватный режим или запрет localStorage может ограничить сохранение — приложение сообщит об этом.

## Настоящий API и адаптация

Типы в `src/api/types.ts` — модель для компонентов. Реальный формат FastAPI отличается от неё; `src/api/wire.ts` проверяет и преобразует ответы. Числовые эффекты и официальный результат остаются за сервером.

| HTTP | Назначение адаптера |
| --- | --- |
| `GET /api/catalog` | direction → directionId; правила, события, синергии и районные конфликты из backend |
| `POST /api/simulate` | Официальный result или preview допустимого незавершённого плана; базовые показатели и событие |
| `POST /api/explain` | status fallback_no_ai → понятное UI-состояние fallback, сохранение привязки текста к району |
| `POST /api/improve` | populationCount/globalOptimum/bestSingleSwap → точный процентиль, оптимум и diff замены |
| `POST /api/events/draw` | Серверные идентификаторы событий, заголовок, эффекты, бюджет; excludeId исключает повтор |
| `GET/POST /api/leaderboard` | Обёртка entries и UTC-время записи; одна запись на имя команды, версию и правила |
| `POST /api/presentation` | Markdown-отчёт, подготовленный сервером |

Запрос плана содержит `{ decisions: [{ measureId, districtId }], eventId }`. Стоимость и баллы браузер в него не отправляет. Неверный план не получает ни официального результата, ни preview. Допустимый незавершённый набор получает только preview; он не может попасть в лидерборд.

HTTP-граница проверяет структуру ответов, конечность чисел и совместимость версии данных/правил. Вложенные ошибки FastAPI становятся читаемым сообщением. Обычный таймаут — 45 секунд, холодный поиск оптимума — 120 секунд. Защита от запоздавших ответов находится в хуках и состоянии интерфейса; повторный запрос сохраняет выбранный план.

При событии общий рейтинг и оптимизатор недоступны, потому что исходные условия отличаются. Анализ и экспорт доступны для допустимого сценария с событием.

## Локальное демо

`src/api/mock` содержит самостоятельный расчёт по синтетическому датасету. Демо явно подписано; анализ в нём формируется по правилам, рейтинг хранится локально и не попадает на сервер. Точный процентиль не заявляется. После загрузки ресурсов API для этого режима не нужен, но PWA и гарантированного запуска с нуля без сети нет.

## Где что находится

| Путь | Ответственность |
| --- | --- |
| `src/App.tsx` | Общий сценарий: каталог, карта, фиксация, сравнение, события и анализ |
| `src/components/catalog`, `city`, `portfolio` | Выбор мер, drag and drop, схема и портфель |
| `src/lib/availability.ts` | Причины недоступности и подсказки района |
| `src/state/planState.ts`, `usePlan.ts` | Проверяемый черновик, сохранение, отмена и план А |
| `src/state/useSimulation.ts` | Пересчёт, повтор и защита от устаревшего ответа |
| `src/api/http.ts`, `wire.ts` | Сеть и адаптер реального backend |
| `src/api/__fixtures__/backend.json` | Эталонные ответы Python TestClient без обращения к AI |
| `src/index.css` | Адаптация размеров, проектор, печать и reduced motion |

Эталон для проверки: пример организаторов, без события, `dataset` — стоимость 95, Score 56.54307, прирост 3.98539, критических значений 0. Ручные проверки и фактические ограничения перечислены в [UX-чеклисте](../Доки/ux-checklist.md).
